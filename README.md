# MHGU Wishlist v1.0.0

A Forge wishlist mod for Monster Hunter Generations Ultimate (global 1.4.0) on MHGU Recomp.

Track up to 48 equipment recipes per character, inspect required and total materials, receive material-ready notifications, and automatically remove completed crafting or upgrade entries. Includes nine languages, Nintendo/Xbox/PlayStation button icons, and persistent UI settings.

See [한국어 README](README_KO.md) for installation, controls, settings, and source build instructions.

Release archive: `Wishlist_v1.0.0.zip`. Extract its `Wishlist` folder into Recomp's `mods` directory.
